# Security policy / Politique de sécurité

## Reporting a vulnerability

Please **do not open a public issue** for a security vulnerability.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/SethLawson07/autoroute/security/advisories/new). Include a description of the issue, the steps to reproduce it and the affected version.

You will get an answer as soon as possible. Once a fix is released, the vulnerability will be disclosed in the release notes.

Only the latest released version receives security fixes.

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Signale-la en privé avec le [signalement privé de GitHub](https://github.com/SethLawson07/autoroute/security/advisories/new). Indique une description du problème, les étapes pour le reproduire et la version concernée.

Tu recevras une réponse dès que possible. Une fois le correctif publié, la faille sera mentionnée dans les notes de version.

Seule la dernière version publiée reçoit les correctifs de sécurité.

## Scope / Périmètre

Autoroute has no server: API keys and prompts never leave the user's machine except to call the providers' APIs directly. Vulnerabilities in the providers' APIs or in LangChain should be reported to them.

Autoroute n'a pas de serveur : les clés API et les prompts ne quittent la machine de l'utilisateur que pour appeler directement les API des fournisseurs. Les failles des API des fournisseurs ou de LangChain sont à leur signaler directement.
